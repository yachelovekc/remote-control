# RemotePhone: Удаленный доступ ко второму Android-телефону

Система автономного удаленного доступа и управления вторым телефоном через интернет (WebRTC) с нулевыми затратами (бесплатный Supabase Realtime + бесплатный TURN).

---

## Возможности системы

- **Полное управление экраном**: трансляция экрана в реальном времени с минимальной задержкой + тапы, свайпы и жесты прямо по экрану контроллера.
- **Аппаратные кнопки**: `Назад`, `Домой`, `Недавние`, `Разбудить экран` (Wake), `Погасить/Заблокировать` (Lock).
- **Камеры и микрофон**: переключение на ходу между трансляцией экрана, задней и фронтальной камерами + передача звука с микрофона.
- **Файловый менеджер**: просмотр файлов и папок на втором телефоне, быстрое скачивание и загрузка файлов с основного телефона, удаление.
- **Полная автономность и незаметность**:
  - Агент не отображается в списке запущенных вкладок (`excludeFromRecents="true"`).
  - Автозапуск при включении/перезагрузке телефона (`BOOT_COMPLETED`).
  - Пробуждение экрана при удаленном подключении и гашение после сеанса.
  - Работа без Root (все необходимые системные разрешения выдаются один раз через ADB).

## Шаг 1. Бесплатный сервер сигналинга (Supabase)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (бесплатный тариф).
2. Нажмите **New Project** (название любое, например `remotephone`).
3. Перейдите в **Project Settings -> API**:
   - Скопируйте **Project URL** (например `https://abcdefghijkl.supabase.co`).
   - Скопируйте **anon / public key**.
4. *(Опционально для мобильного 4G/5G интернета)*: зарегистрируйтесь на [metered.ca/tools/openrelay](https://www.metered.ca/tools/openrelay) и скопируйте бесплатные реквизиты TURN-сервера (50 ГБ в месяц бесплатно).

---

## Шаг 2. Сборка APK через GitHub Actions

Вам не нужно устанавливать тяжелый Android SDK на телефон или ПК — сборка происходит в облаке GitHub:

1. Создайте новый приватный репозиторий на [github.com](https://github.com).
2. Запушьте код из этой папки:
   ```bash
   cd ~/remote-phone
   git remote add origin https://github.com/<ваш-логин>/<ваш-репозиторий>.git
   git add .
   git commit -m "Initial commit"
   git push -u origin main
   ```
3. Откройте вкладку **Actions** в вашем репозитории на GitHub.
4. Процесс сборки начнется автоматически. Через 2–3 минуты появится артефакт **`RemotePhone-Agent-Debug-APK`**.
5. Скачайте `app-debug.apk` на второй телефон.

## Шаг 3. Установка и ADB-настройка второго телефона (1 раз)

1. Установите скачанный `app-debug.apk` на второй телефон.
2. Включите **Отладку по USB** (USB Debugging) в параметрах разработчика.
3. Подключите второй телефон кабелем к ПК (или к основному телефону через OTG/Termux) и запустите скрипт:
   ```bash
   ./scripts/setup-second-phone.sh
   ```
   Этот скрипт выдаст все системные разрешения:
   - Трансляция экрана без всплывающего окна (`PROJECT_MEDIA allow`).
   - Доступ к файловой системе (`MANAGE_EXTERNAL_STORAGE allow`).
   - Камера, микрофон, уведомления.
   - Автоматически активирует службу специальных возможностей (`RemoteAccessibilityService`).
   - Исключит из оптимизации батареи (`dumpsys deviceidle whitelist`).
4. Откройте приложение `RemotePhone Agent` на втором телефоне:
   - Введите ваш **Supabase URL**, **Anon Key**, придумайте **ID телефона** (например `phone2`) и **пароль**.
   - Нажмите **«Сохранить и запустить в фоне»**.
   - Окно закроется и **не будет отображаться в списке недавних вкладок**. Агент готов к работе 24/7.

## Шаг 4. Управление с основного телефона

1. Откройте папку `controller-web/`:
   - Вы можете открыть `index.html` прямо в мобильном браузере (Chrome / Safari), либо разместить его на **GitHub Pages** (в настройках репозитория -> Pages), либо запустить локальный сервер в Termux:
     ```bash
     cd ~/remote-phone/controller-web
     python3 -m http.server 8080
     ```
2. В веб-интерфейсе введите те же данные:
   - **Supabase URL**, **Anon Key**, **Device ID** (`phone2`) и **Пароль**.
3. Нажмите **«Подключиться»**:
   - На экране основного телефона появится экран второго телефона в реальном времени.
   - Одиночные касания по экрану воспроизводятся на втором телефоне.
   - Кнопка **💡 Разбудить** включает экран и снимает блокировку свайпом.
   - Кнопка **🔒 Погасить** блокирует экран после завершения сеанса.
   - Выпадающий список режимов позволяет переключиться на **Заднюю камеру**, **Селфи-камеру** или **Только звук**.
   - Кнопка **📁 Файлы** открывает проводник для скачивания и отправки файлов.
